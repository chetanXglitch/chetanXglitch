Binary exploitation is one of the areas I'm especially interested in. I'm working on understanding how compiled programs execute, how memory is organised, and how programming mistakes can turn into security vulnerabilities.

### 🧠 Concepts I'm exploring

- 📦 **ELF binaries:** executable structure, sections, segments, symbols, and imports
- 🧱 **Stack fundamentals:** stack frames, local variables, saved registers, and function calls
- 💥 **Buffer overflows:** understanding out-of-bounds writes and how memory corruption occurs
- 🧭 **Instruction pointers:** understanding RIP/EIP, registers, control flow, and calling conventions
- 🔗 **ROP — Return-Oriented Programming:** how existing instruction sequences can be chained in vulnerable programs
- 🗃️ **Heap exploitation fundamentals:** dynamic allocation, free lists, allocator behaviour, and tcache concepts
- 🛡️ **Mitigations:** NX, PIE, ASLR, stack canaries, and RELRO
- 🔬 **Debugging:** using GDB, breakpoints, registers, stack inspection, and memory examination
- 🧩 **CTF challenges:** analysing small binaries and learning to explain the complete exploitation process

### ⚙️ My binary-analysis workflow

```text
        📂 Obtain a challenge binary
                  |
                  v
        🔎 Identify file type & architecture
                  |
                  v
        🛡️ Inspect protections (checksec)
                  |
                  v
        🧠 Analyse with GDB / Ghidra
                  |
                  v
        🧪 Reproduce behaviour in a local lab
                  |
                  v
        💣 Understand the vulnerability
                  |
                  v
        📝 Document findings & mitigations
```

My goal is to understand the **why behind the exploit**: what went wrong in memory, which protections matter, what the debugger reveals, and how the underlying bug should be fixed.

### 🔐 02 — Quantum Vault | Encrypted File Storage

🔗 **Repository:** [quantum-vault](https://github.com/chetanXglitch/quantum-vault)

An experimental secure-file-storage project exploring encryption, fragmented key handling, recovery workflows, and dead-man-switch concepts.

**⚡ Key features**

- 🔒 File-encryption workflow using AES-256-CBC
- 🧩 Three-fragment key-handling concept
- 🖥️ Node.js and Express backend
- 🌐 Web interface for vault operations
- ⏳ Dead-man-switch and check-in workflows
- 🔑 Manual key-fragment entry during decryption

**🧰 Stack:** Node.js · Express · JavaScript · Cryptography · REST APIs

**🎯 Learning outcome:** Exploring secure file handling, key management, backend API design, and recovery workflows.

*Note: This is an experimental project, not a formally audited cryptographic system. Its implementation should not be assumed to provide quantum-resistant security.*
