## 🚀 `$ ls ./projects`

### 🛡️ [ShadowPulse — Security Assessment Platform](https://github.com/chetanXglitch/cybersec2)

A web-based reconnaissance and vulnerability-scanning project built around a dashboard, controller–agent communication, and security assessment workflows.

- 🌐 Django-based dashboard and scan management
- 🔌 TCP request–response communication between controller and agent
- 🔍 Port scanning, service discovery, and network reconnaissance
- 🧠 CVE correlation and vulnerability assessment
- 📊 Scan results and report generation

**Stack:** Python · Django · TCP Sockets · Networking · CVE Correlation

### 🔐 [Quantum Vault](https://github.com/chetanXglitch/quantum-vault)

An encrypted file-storage project exploring cryptographic key handling, fragmented key storage, recovery workflows, and a dead-man switch.

- 🔒 AES-256-CBC-based file encryption
- 🧩 Three-fragment key-handling workflow
- 🖥️ Node.js and Express backend with a web interface
- ⏳ Dead-man switch and recovery-management concepts
- 🔑 Manual key-fragment entry for decryption

**Stack:** Node.js · Express · JavaScript · Cryptography · REST APIs

*An experimental security project—not a claim of formally audited or quantum-resistant cryptography.*

### 🎣 PhishNet Detector

A phishing-detection project focused on exploring suspicious URLs, identifying potentially malicious patterns, and improving awareness of web-based threats.

**Focus:** Phishing Detection · Web Security · Security Automation

### 🧬 AI-Assisted Binary Reverse Engineering

Exploring how AI agents could assist reverse engineering by interpreting binary-analysis artifacts and suggesting useful next steps.

- ⚙️ Exploring Ghidra and decompiler output
- 🧭 Control-flow graphs, strings, imports, and cross-references
- 🤖 Investigating LLM-assisted analysis workflows
- 🔬 Learning how to connect low-level binary evidence with higher-level explanations

*Research and experimentation in progress.*
